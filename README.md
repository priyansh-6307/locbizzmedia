# LOCBIZZ MEDIA

A static creative-studio site based on the supplied Lunchbox reference, with LOCBIZZ MEDIA branding and the requested home introduction/client-logo section omitted.

Run `npm start` to preview at http://127.0.0.1:4173. Run `npm run build` after editing `build.py` or `content/`; the stylesheet and browser JavaScript are authored directly in `dist/`. Run `npm run check` to validate generated routes and assets.

The site includes Home, Projects, About, Contact, Blog, 12 project pages, and 8 article pages. Inter Display and Chivo Mono match the reference fonts. Its LOCBIZZ MEDIA logo is a custom black-and-white hand-cut wordmark generated from the supplied visual direction.

Project imagery, client marks, and remotely hosted films are retained from the design reference. Project descriptions and blog articles are adapted copy. Replace these reference projects with LOCBIZZ's own portfolio when ready. Video availability depends on the original media host.

Forms open an email draft addressed to priyanshyadav364@gmail.com. They do not silently send email or store submissions. Instagram and LinkedIn destinations were not provided, so the site uses an email link instead.

The `.openai/hosting.json` file records the existing Sites project; reuse its ID for future updates.
